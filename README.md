# AI Product Knowledge Hub

Привет. А можешь помочь создать сайт в формате faq? Ну, т.е. есть основный сайт и я хочу создать еще сайт приложение к первому в формате FAQ, чтобы ии агенты могли обращаться к нему и получать информацию по продукту.

## Content

All questions and answers live in `src/data/faq.ts`. The page, `/q/<slug>`, `faq.json`, `llms-full.txt` and the sitemap render from it; `public/llms.txt` is regenerated by `scripts/generate-llms.mjs` (run automatically by `npm run build:pages`). Update `FAQ_UPDATED` when answers change.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
